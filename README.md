# emmafolio

Premium developer portfolio of **Ashutosh Palhare (AP)**.

Built with **Vite + React + TypeScript + Tailwind CSS + Framer Motion**.

## Features

- Modern & cinematic UI
- Smooth Framer Motion animations
- Dark / Light mode
- Fully responsive
- GitHub Pages ready

## Tech Stack

- React 19
- Vite 6
- TypeScript
- Tailwind CSS
- Framer Motion
- React Icons
