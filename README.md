# emmafolio

**Premium modern portfolio of [Ashutosh Palhare (AP)](https://github.com/ashutoshpalhare)**

A cinematic, fully responsive personal portfolio built with cutting-edge frontend technologies. Designed to showcase skills, projects, and personality with smooth animations and a clean developer aesthetic.

🔗 **Live Demo**: [ashutoshpalhare.github.io/emmafolio](https://ashutoshpalhare.github.io/emmafolio/)

---

## ✨ Features

- Modern & cinematic UI design
- Smooth animations powered by Framer Motion
- Dark / Light mode toggle
- Fully responsive (Mobile + Tablet + Desktop)
- Clean section-based layout (Hero, About, Skills, Work, Contact)
- GitHub Pages ready with automated deployment
- Optimized performance with Vite

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

# Clone the repository
git clone https://github.com/ashutoshpalhare/emmafolio.git

# Navigate to project
cd emmafolio

# Install dependencies
npm install

# Start development server
npm run dev


Open http://localhost:5173 to view it in the browser.
